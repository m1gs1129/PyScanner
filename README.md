# PyScanner 🚀

**PyScanner** is a lightweight, web-based utility designed to analyze, inspect, and process Python code and scripts directly in the browser.

🔗 **Live Website:** [pyscanner.js.org](https://pyscanner.js.org)

---

## ✨ Features

- **Instant Code Analysis:** Quick inspection of Python syntax and script structures.
- **Client-Side Processing:** Runs fast and securely in your browser.
- **Clean & Intuitive Interface:** Minimalist design focused on developer efficiency.

---

## 🛠️ Built With

- **HTML5 & CSS3**
- **JavaScript (ES6+)**
- Hosted on **GitHub Pages** with custom domain routing via **JS.org**
